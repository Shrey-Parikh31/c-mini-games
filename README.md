# C Mini-Games

Small self-contained games written in C/C++ for fun alongside coursework:

- `dinogame.cpp` — a terminal clone of Chrome's offline dino game
- `2048.c` — the sliding-tile puzzle game
- `hangman.c` — classic word-guessing game
- `cquizgame.c` — a console quiz game
- `wordle2.c` — a CS50-style Wordle clone

Each file is standalone — compile individually with gcc/g++.
